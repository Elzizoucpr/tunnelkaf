📋 Étape 1 — Copiez le script de configuration
Ce script configure automatiquement le tunnel WireGuard sur votre MikroTik RouterOS. Cliquez Copier puis passez à l'étape suivante.

    

    

      
    

  


  
  

    
💻 Étape 2 — Ouvrez le terminal MikroTik

    
Choisissez votre méthode d'accès au terminal RouterOS :

    

      

        
A

        

          
Via Winbox (recommandé)

          
Ouvrez Winbox → connectez-vous → menu de gauche → New Terminal

          
 Winbox → Menu gauche → New Terminal

        

      

      

        
B

        

          
Via SSH

          
Depuis votre PC, ouvrez un terminal et connectez-vous en SSH :

          

            
            
ssh admin@192.168.88.1

          

        

      

      

        
C

        

          
Via WebFig (navigateur)

          
Accédez à votre MikroTik dans le navigateur → WebFig → Terminal

          
 http://192.168.88.1 → WebFig → Terminal

        

      

    

    

      
      
    

  


  
  

    
⚡ Étape 3 — Collez et exécutez le script

    
Dans le terminal MikroTik (Winbox / SSH / WebFig) :

    

      

        
1

        

          
Collez le script

          
Ctrl+V (ou clic droit → Coller) dans le terminal. Le script configure tout automatiquement.

          

            [admin@MikroTik] > /interface wireguard

            [admin@MikroTik] /interface/wireguard> add name=nexotik-wg0 ...

                ; Collez ici tout le contenu copié ...
          

        

      

      

        
2

        

          
Appuyez sur Entrée

          
Après avoir collé, appuyez sur Entrée. Le script s'exécute en quelques secondes.

          

            ✔ WireGuard interface created: nexotik-wg0

            ✔ Peer added successfully

            ✔ IP address assigned: /24

            ✔ Firewall rules added

            ✔ Route configured

            >>> TUNNELKAF tunnel  ready !
          

        

      

    

    

      
      
    

  


  
  

    
✅ Étape 4 — Vérifiez la connexion

    
Copiez ces commandes de vérification dans le terminal MikroTik :

    

      

        
1

        

          
Vérifier l'interface WireGuard

          

            
            
/interface wireguard print

          

          

            Flags: X - disabled, R - running

            0  R  name="nexotik-wg0"  mtu=1420  listen-port=51820

               public-key="..."
          

        

      

      

        
2

        

          
Vérifier le handshake (peer)

          

            
            
/interface wireguard peers print

          

          

            0  interface=nexotik-wg0

               endpoint-address=peer.nexotik.bf  endpoint-port=51820

               last-handshake=2s ago ← Doit être récent !
          

        

      

      

        
3

        

          
Tester le ping vers TUNNELKAF

          

            
            
/ping 10.60.0.1

          

          

              SEQ  HOST        SIZE  TTL  TIME   STATUS

                0  10.60.0.1     56   64   4ms

                1  10.60.0.1     56   64   3ms

                sent=2 received=2 packet-loss=0%
          

        

      

    

    

      
      

        
Tunnel configuré avec succès !

        
Votre MikroTik est connecté à TUNNELKAF. Le statut passera à Actif dans quelques secondes.
